# Robot pictures

The five robot photos are real robots like each starter project, built by other makers and shared on Wikimedia Commons. They were cropped to the card shape (960 × 690) and saved without camera metadata. In the rover photo, a person in the background was blurred. Replace any of them with photos of your own builds whenever you like (same file name, about 960 × 690).
